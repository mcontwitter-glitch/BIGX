# BIGX

BIGX — the BIG social app. The social platform for Bigfoot404: sightings feed,
researcher community, spaces, secure crypto wallet, and messaging.

This repo is the source home for the **BIG** app (Base44). It is separate from
[BIG-Terminal](https://github.com/mcontwitter-glitch/BIG-Terminal), the swarm
network HUD client.

## App

- Platform: Base44 app "BIG"
- Entities: Post, Comment, Wallet, Transaction, Conversation, Message, Space,
  Repost, Notification, Bookmark, Badge
- Publish target: synced from the Base44 editor via the GitHub integration

## Note

App source syncs here through the Base44 GitHub connection (Settings → GitHub in
the BIG app editor, choose this repo). Do not push the BIG Terminal codebase here.
